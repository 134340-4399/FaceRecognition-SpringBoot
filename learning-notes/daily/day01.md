## 学习内容记录

### 1. 项目结构分析
通过查看项目文件和目录，理解了项目的整体组织结构：

**包结构梳理**：
- `controller/`：包含6个控制器，处理不同业务模块的HTTP请求
- `dao/`：数据访问层，使用Spring Data JPA Repository模式
- `entity/`：JPA实体类，对应数据库表
- `service/`：业务逻辑层（目前只有FaceService）
- `utils/`：工具类，包含人脸识别核心功能
- `config/`：配置类
- `interceptor/`：JWT认证拦截器

**资源文件**：
- `model/`目录包含3个ONNX模型文件，用于人脸检测和识别
- `application.properties`配置了数据库连接和JPA设置

### 2. 技术栈识别
详细分析了`pom.xml`中的依赖：

**核心框架**：
- Spring Boot 3.2.0 + Java 17
- Spring Web MVC
- Spring Data JPA + MySQL

**人脸识别技术**：
- JavaCV (javacv-platform)：计算机视觉库
- ONNX Runtime：机器学习模型推理
- YOLOv8 + ArcFace模型

**安全认证**：
- JWT (Java JWT 4.4.0)
- Spring Security Crypto
- 自定义RSA加密工具

**开发工具**：
- Lombok减少样板代码
- Maven构建工具

### 3. 配置文件解读
`application.properties`关键配置：
- 数据库连接：MySQL `face_attendance`数据库
- JPA设置：显示SQL、自动更新表结构
- 服务器端口：8080

### 4. 架构图绘制
使用Mermaid绘制了系统架构图，包含：
- 客户端层（Web浏览器）
- 应用层（Spring Boot各模块）
- 数据层（MySQL数据库）
- 模型层（ONNX模型文件）

## 关键代码片段理解

`convert_model.py`文件的作用：
- 将YOLOv8模型转换为ONNX格式
- 调整ONNX模型的opset版本
- 确保模型与ONNX Runtime兼容

### 实体类设计
通过文件名推断实体关系：
- `Employee`：员工基本信息
- `Department`：部门信息  
- `AttendanceLog`：考勤记录
